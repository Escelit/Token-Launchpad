# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-07

### Added

- Soroban smart contract: initialize, contribute, claim, fund, withdraw_deposits, cancel, refund
- Vesting with configurable cliff + linear release
- React + TypeScript frontend with Tailwind CSS v4
- Freighter wallet integration
- TypeScript contract bindings
- CLI management scripts (deploy, initialize, manage sale)
- CI pipeline (contract tests + frontend build)
- Full documentation (README, CONTRIBUTING, CODE_OF_CONDUCT, LICENSE)
